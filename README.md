# clpolite-web-project
## Project 2 - HTML Foundation Page

For Project 2, I created a simple two-page website using only HTML. My theme is Demon Slayer, an anime series that I enjoy because of its story, characters, and action scenes.

While creating this page, I learned how to structure an HTML document, connect multiple pages using navigation links, add images, create lists, and build tables.

One challenge I faced was making sure my file paths were correct for images and links. I also had to fix HTML errors such as broken tags and incorrect formatting to get everything to display properly.
